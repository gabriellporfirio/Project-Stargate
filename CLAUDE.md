# Rules for AI assistants in this repo

- This is a planning repo. Write plans, specs, reviews and mockups only. Product code is written by Meta's Muse CLI elsewhere (hackathon rule).
- `plan/master-plan.md` is the source of truth. Change it only through a pull request, and record each decision in its section 7 with the date and reason.
- Never assume facts: mark them unknown or add them to the open-questions table.
- Never include anything from the owner's production StarGate/VPN setup (addresses, configs, keys, topology).
- Write in plain English for a non-specialist reader.
